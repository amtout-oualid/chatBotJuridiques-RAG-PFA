DIAGRAM 1: ENTERPRISE LOGGING SYSTEM ARCHITECTURE
================================================================================
```mermaid
flowchart TD
    subgraph Sources["Event Sources (FastAPI Context)"]
        Req[FastAPI HTTP Middleware]
        DB_Events[SQLAlchemy Event Listeners]
        RAG_Events[RAG Pipeline Operations]
        AI_Events[Gemini / External APIs]
    end

    subgraph Processing["Logger Module (logger.py)"]
        Context[ContextVars: correlation_id]
        Formatter[JSONFormatter]

    end

    subgraph Handlers["Log Handlers"]
        Stdout[StreamHandler: stdout]
        TRFH[TimedRotatingFileHandler: Midnight, 30 Days]
    end

    subgraph Outputs["Log Files (/logs)"]
        AppLog[app.log]
        RagLog[rag.log]
        DbLog[db.log]
        ChromaLog[chromadb.log]
        AllLog[all.log]
    end

    subgraph Rotation["Lifecycle Management"]
        Compressor[GZIP Compressor]
        Archive[(Archived .gz logs)]
        Delete[Auto-delete > 30 days]
    end

    Sources -->|Emits Record| Processing
    Context -.-> Formatter
    Formatter --> Scrubber
    Scrubber --> Handlers
    
    Handlers --> Stdout
    Handlers --> Outputs
    TRFH --> Outputs

    Outputs -->|Midnight Trigger| Compressor
    Compressor --> Archive
    Archive --> Delete

    style Processing fill:#f9f,stroke:#333,stroke-width:2px
    style Scrubber fill:#ff9,stroke:#e60,stroke-width:2px
```

================================================================================
DIAGRAM 4: ADVANCED RAG PIPELINE (Execution Flow)
================================================================================
```mermaid
flowchart TB
    %% Definitions
    User([User Query])
    Gemini1(((Gemini 2.5 Flash\nCall 1: Decomposition)))
    Gemini2(((Gemini 2.5 Flash\nCall 2: Generation)))
    Chroma[(ChromaDB)]
    Answer([Final AI Response])

    subgraph "Phase 1: Memory & Translation"
        direction TB
        Mem[Fetch Conversational Memory\nLast 6 Messages]
        Trans[Translate & Decompose\nComplex Query into Array]
    end

    subgraph "Phase 2: Multi-Query Retrieval"
        direction TB
        Loop[[For Each Sub-Query]]
        Embed[BAAI/bge-m3 Embedder]
        Search[Cosine Search\nTop 15 Chunks]
        Rerank[BAAI/bge-reranker-v2-m3\nTop 5 Chunks]
        
        Loop --> Embed
        Embed --> Search
        Search --> Rerank
    end

    subgraph "Phase 3: Assembly & Fallback"
        direction TB
        Dedup[Deduplicate Unique Chunks\nPreserve All Context]
        Prompt[Assemble Final Prompt\nContext + Memory + Query]
        Rule{Is Context Sufficient?}
        Fallback[Graceful Fallback\nGeneral Knowledge + Disclaimer]
        Strict[Strict Generation\nBased ONLY on Context]
    end

    User --> Mem
    Mem --> Trans
    Trans -->|Prompt + Memory| Gemini1
    Gemini1 -->|JSON Array of Sub-Queries| Loop

    Rerank --> Dedup
    Dedup --> Prompt
    
    Prompt --> Gemini2
    Gemini2 --> Rule
    Rule -->|Yes| Strict
    Rule -->|No| Fallback
    
    Strict --> Answer
    Fallback --> Answer
    
    Chroma -.->|Vector Matches| Search

    style Gemini1 fill:#fff0f5,stroke:#333,stroke-width:2px
    style Gemini2 fill:#fff0f5,stroke:#333,stroke-width:2px
    style Chroma fill:#f4f4f4,stroke:#333,stroke-width:2px
    style Fallback fill:#ffe6e6,stroke:#e60000,stroke-width:2px
```
